# Contact Management System (C++)

A simple file-based Contact Management System built using **C++**, **OOP concepts**, and **STL**.

## Features
- Add new contacts
- Multiple phone numbers and emails per contact
- Search contact by ID or Last Name
- Update contact details
- Delete contacts
- File storage using `.dat` file
- Data persists after program exit

## Technologies Used
- C++
- OOP (Classes & Objects)
- STL (vector, string)
- File Handling
